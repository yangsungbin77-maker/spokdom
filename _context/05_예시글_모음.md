# 05. 예시 글 모음 (가장 강력한 레퍼런스)

Dom 톤이 잘 적용된 글을 여기에 모은다. 새 글 쓸 때 "이 톤·문장 길이·구조를 거의 그대로 따라 하라(almost mimic)"고 지시한다.

> ⚠️ **블로그 출력 언어 = 영어.** 아래 예시 글들은 이미 영어 본문이고, 우리가 원하는 정직한 리서치 기반 1인칭 톤이 굳어 있다.

## 기준 예시 (페르소나 모범 — 이미 톤이 맞음)
- **`src/content/blog/best-ai-tools-for-solo-founders.md`** — 'Dom' 톤의 1호 레퍼런스.
  - 본받을 점: 도입에 **정직한 비교 방법 고지**를 넣음 — *"I didn't run a 12-month lab test of every plan. This guide compares tools on their public pricing and feature data as of June 2026, plus hands-on familiarity with the mainstream options. Prices change often, so treat every number as a starting point and confirm on the official page before you pay."* → 이게 우리가 원하는 안전한 1인칭의 표준이다.
  - "what does this replace, and is it worth the subscription?" 판단 기준, "What to skip" 섹션, 비교표 + "Best for" 열, "as of June 2026" 가격 시점 표기, FAQ 5개까지 전부 모범.

- **`src/content/blog/calendly-alternatives-without-branding.md`** — 비교형(alternatives) 클러스터 모범.
  - 본받을 점: "정직한 catch 고지"("we say plainly when white-label is paid or requires self-hosting"), 무료 티어가 어디서 paywall 걸리는지 명확화, 비교표 + "Best for", 시점 고지("Vendors change free-tier rules often, so verify the badge policy on each tool's own pricing page"), 같은 클러스터 글로 내부링크.

## 추가 예정
- Dom 페르소나로 새로 쓰거나 리라이트한 글이 나오면 여기에 경로를 계속 추가한다.
- 가장 잘 나온 2~3편만 유지(너무 많으면 톤이 흐려짐).
